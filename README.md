## Contribuição em Projeto Open Source (DIO)

Este repositório foi utilizado como parte de um laboratório prático da Digital Innovation One (DIO), com foco em aprender e aplicar o fluxo de contribuição em projetos open source utilizando Git e GitHub.

---

### 🚀 Atividades realizadas

Durante o desenvolvimento deste projeto, foram praticados os seguintes conceitos:

- Fork de repositório open source  
- Edição e criação de arquivos  
- Versionamento com Git  
- Criação de commits  
- Envio de Pull Request  
- Estruturação de um Profile README  

---

### 🔗 Contribuição

A partir deste laboratório, foi realizada uma contribuição em um repositório open source por meio de fork e Pull Request.

> (Você pode inserir aqui o link do seu fork ou PR, se quiser destacar ainda mais sua participação.)

---

### 🛠️ Tecnologias utilizadas

- Git  
- GitHub  
- Markdown  

---

### 💡 Aprendizados

Este projeto foi importante para consolidar, na prática, o processo de contribuição em projetos open source, incluindo o uso de fork, branches, commits e pull requests.

Além disso, ajudou a desenvolver uma melhor compreensão sobre colaboração em equipe utilizando controle de versão.
